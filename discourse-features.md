# Discourse Platform Features

## Core Discussions
- Infinite-scroll topics (no pagination)
- Flat reply flow with expandable context
- Nested/tree replies (experimental in v2026)
- Markdown, BBCode, HTML formatting
- Onebox link previews (auto-expand YouTube, GitHub, etc.)
- Post revision history
- Wiki posts (collaborative editing)
- Embeddable polls
- Spoiler tags
- File attachments, drag & drop image uploads
- Auto-save drafts
- Summarize button (AI condenses long topics)
- Solved/answered topics (Q&A mode with Support category type)
- Topic voting plugin
- Bookmark system with calendar sync

## Chat & Messaging
- Built-in real-time chat channels
- Personal messages / DMs
- Reply via email from any device
- Chat messages quotable into topics

## User System
- Trust levels (0–4) with automated promotion
- Gamification: badges, likes, reading time, cakeday
- Custom user groups (self-managing)
- Anonymous posting
- Custom & automatic avatars

## Moderation
- Flag/review queue (community-assisted moderation)
- Inline & bulk moderation
- Post approval workflows (per-category)
- Staff action logs with reviewable links
- Sitewide alerts & pinned topics
- Private categories / invite-only mode
- Bulk pin/unpin, bulk tag management

## AI Features
- AI spam detection
- AI moderation agents with human-in-the-loop
- AI bot conversations (starred, docked composer)
- Content translation (49 languages)
- Topic summarization

## Notifications
- Desktop notifications
- Automatic email digests when offline
- In-app notification center
- Solved topic notifications for watchers

## Integrations
- SSO: Google, Facebook, X, Discord, GitHub
- OAuth2, OpenID Connect, SAML
- DiscourseConnect (custom SSO)
- Group sync from OIDC/OAuth2 providers
- Blog integration (embed full Discourse as comment system)
- Zendesk, Patreon plugins
- Webhooks & comprehensive REST API
- Data Explorer (SQL analytics with charts)
- Embeddable iframe mode

## Admin & Analytics
- Dashboard with community health metrics
- Advanced reporting (Business tier)
- SEO optimized for Google
- Incoming/outgoing link tracking
- Automatic backups
- One-click updates
- Custom outgoing email

## Customization
- Custom themes & components (marketplace)
- Custom domain
- Custom emoji sets
- Dark mode, WCAG color scheme
- Sidebar + user preference controls

## Plugins (Official)
Events, Docs, Topic Voting, Solved, Gamification, Cakeday, Patreon, Zendesk, Data Explorer, Google Adsense, Calendar, AI, Chat, Discourse Assign, and 50+ more

## Enterprise
- Dedicated infrastructure + SLA guarantees
- Custom development & integrations
- White-glove onboarding
- Self-host or managed cloud
- Full data ownership, export anytime
- 100% open source (MIT, on GitHub)

## Technical Stack
Ruby on Rails (backend), Ember.js (frontend), PostgreSQL, Redis

## Release Model
- Monthly stable releases with ~2 months security support
- ESR (Extended Support Release) every 6 months with ~8 months support
- Latest build stream with continuous updates
